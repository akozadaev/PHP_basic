# Лекции по языку PHP

Курс лекций по основам PHP 8.x для начинающих разработчиков.

## Требования

- PHP 8.5.12 или более новый стабильный выпуск ветки 8.5 (см. раздел безопасности)
- Совместимость с Laravel Sail

## Безопасность и переход на PHP 8.5.12

Сведения проверены 12 ноября 2026 года. Для курса используйте **PHP 8.5.12 или более свежий стабильный выпуск ветки 8.5**. Возможности языка из примеров доступны с PHP 8.0, но это не основание оставаться на старом интерпретаторе.

PHP выпустил [экстренное обновление безопасности 21 октября 2026 года](https://www.php.net/archive/2026.php#2026-10-21-5). В PHP 8.5.12 исправлены две критические уязвимости, допускающие удалённое выполнение кода без аутентификации (RCE):

| Уязвимость | Причина и исправление |
|---|---|
| [CVE-2026-109618 — RCE via OOM corruption](https://github.com/php/php-src/security/advisories/GHSA-w8hw-w9fx-j79w) | При нехватке памяти обработка запроса прерывается с частично инициализированными внутренними данными. Последующая очистка может использовать их как корректные. Исправлена обработка состояния при аварийном прерывании. |
| [CVE-2026-109619 — RCE via stale global state](https://github.com/php/php-src/security/advisories/GHSA-6wmf-4rv5-p3rp) | Состояние запроса может пережить освобождение связанной памяти и использоваться следующим запросом в том же рабочем процессе. Исправлено сохранение некорректного состояния. |

Риск касается веб-установок, включая PHP-FPM, mod_php, CGI, FrankenPHP и LiteSpeed; особенно высок риск для mod_php. Настройки и изменения прикладного кода не заменяют обновление интерпретатора. Исправления также доступны в 8.4.27, 8.3.36 и 8.2.35: для существующего приложения допустимо обновление своей поддерживаемой ветки. PHP 8.1 и старше больше не поддерживаются самим проектом PHP. [Официальные рекомендации](https://www.php.net/archive/2026.php#2026-10-21-5).

Порядок перехода:

1. Установите обновлённый PHP из доверенного репозитория ОС или [официальных загрузок](https://www.php.net/downloads.php). Для Sail обновите среду контейнера и пересоздайте контейнеры.
2. Проверьте совместимость приложения, зависимостей и расширений по [руководствам миграции PHP](https://www.php.net/manual/en/appendices.php), затем выполните тесты и примеры.
3. Перезапустите PHP-FPM/Apache или контейнеры, чтобы заменить все старые рабочие процессы.
4. Проверьте `php -v` (для Sail — `sail php -v`). Отдельно проверьте версию PHP, обслуживающего веб-запросы: CLI и веб-сервер могут использовать разные установки. Не оставляйте публичную страницу `phpinfo()`.

**Дополнения после релиза:** PHP рекомендует `session.upload_progress.enabled=0` в конфигурации до следующего исправления из-за отдельного редкого сценария RCE (CVE-2026-115560), связанного со сменой обработчика сериализации сессии во время выполнения. После изменения перезапустите рабочие процессы. Для Windows доступны пересобранные пакеты **8.5.12-1** с исправлением Brotli (CVE-2026-111497); номер интерпретатора остаётся 8.5.12. См. [сообщения PHP от 23 и 26 октября](https://www.php.net/archive/2026.php).

Подробности выпуска: [анонс PHP 8.5.12](https://www.php.net/releases/8_5_12.php) и [ChangeLog](https://www.php.net/ChangeLog-8.php#8.5.12). Обновление среды не устраняет ошибки самого приложения, например SQL-инъекции или XSS.

## Возможности PHP 8 из статьи Habr

Теория, пояснения к результатам, задания и частые ошибки — в [лекции 21](lectures/21-php8-features.md).

В [examples/21-php8-features/basic.php](examples/21-php8-features/basic.php) собраны самостоятельные примеры всех десяти тем статьи [«PHP 8 в восьми кусочках кода»](https://habr.com/ru/articles/504356/): атрибуты с Reflection, union types и mixed, возвращаемый static, JIT, throw в выражениях, catch без переменной, завершающая запятая в параметрах, новые строковые функции, Stringable и `$object::class`.

Статья опубликована до выхода PHP 8: предварительный синтаксис атрибутов `<<...>>` заменён на итоговый `#[...]`. Примеры дополнены определениями классов, обработкой исключений и комментариями к результатам.

```bash
php examples/21-php8-features/basic.php

# Необязательный запуск с JIT; требуется загруженное расширение OPcache
php -d opcache.enable_cli=1 -d opcache.jit_buffer_size=64M -d opcache.jit=tracing examples/21-php8-features/basic.php
```

Настройки также приведены в [jit.ini](examples/21-php8-features/jit.ini). JIT компилирует код во время выполнения; этот короткий пример демонстрирует настройку и вычисление, а не измеряет ускорение. Без JIT пример тоже работает. См. [документацию OPcache/JIT](https://www.php.net/manual/en/opcache.configuration.php).

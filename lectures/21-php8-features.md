# Лекция 21: Возможности PHP 8 и обновление интерпретатора

## 1. Теоретическая часть

Лекция дополняет [статью «PHP 8 в восьми кусочках кода»](https://habr.com/ru/articles/504356/) пояснениями к рабочим примерам. Все десять рассмотренных возможностей появились в PHP 8.0. Для занятий используйте обновлённый PHP 8.5.12 или более свежий стабильный выпуск ветки 8.5 согласно [требованиям курса](../README.md#требования).

### Типы и объекты

- **Union type** (`int|float`) разрешает несколько указанных типов. Проверка типов не заменяет проверку допустимых значений, например положительной цены.
- **mixed** допускает любое значение, включая `null`. Применяйте его, когда функция действительно работает с произвольными данными.
- **static в возвращаемом типе** означает объект класса, через который вызван метод. Фабрика с `new static()` сохраняет тип подкласса.
- **Stringable** автоматически реализуется классом с методом `__toString(): string`. Параметр `Stringable` принимает такой объект; для обычных строк и объектов объявите `string|Stringable`.
- **`$object::class`** возвращает имя класса объекта без создания нового экземпляра.

### Атрибуты

Атрибуты — структурированные метаданные классов, методов и других объявлений. В выпущенном PHP используется `#[...]`; предварительный синтаксис `<<...>>` из статьи устарел. Атрибут сам не выполняет бизнес-логику: программа должна прочитать его, например через Reflection.

### Выражения и параметры

`throw` можно использовать внутри выражения, например справа от `??`. Если объект исключения не нужен, в `catch` можно оставить только его тип. Завершающая запятая в объявлении параметров упрощает изменение многострочных сигнатур.

### Строки и JIT

`str_contains()`, `str_starts_with()` и `str_ends_with()` возвращают `bool` и учитывают регистр. Пустая искомая строка даёт `true` во всех трёх функциях.

JIT компилирует части кода во время выполнения и настраивается через OPcache. Для CLI требуется `opcache.enable_cli=1`; буфер и режим задаются отдельно. JIT не гарантирует ускорение любого приложения: измеряйте реальную нагрузку. Пример курса работает и без него. См. [настройки OPcache](https://www.php.net/manual/en/opcache.configuration.php).

## 2. Синтаксис и основные концепции

```php
<?php

declare(strict_types=1);

function lessonPrice(
    int|float $price,
    int $count,
): int|float {
    return $price * $count;
}

function readTitle(array $data): string
{
    return $data['title'] ?? throw new InvalidArgumentException('Нет названия');
}

echo lessonPrice(12.5, 2), PHP_EOL; // 25
try {
    readTitle([]);
} catch (InvalidArgumentException) {
    echo 'Укажите название', PHP_EOL;
}
```

`??` выбирает правую часть и при отсутствии ключа, и при значении `null`. Непустую строку необходимо проверять отдельно.

## 3. Рабочие примеры с пояснениями

Полный пример: [basic.php](../examples/21-php8-features/basic.php). Блоки пронумерованы в порядке тем статьи:

| 2 | Числовой результат `25`, описание типа `null` |
| 3 | Фабрика возвращает `WelcomeMessage` |
| 4 | Сумма квадратов `338350` и состояние JIT |
| 5–6 | Обработка отсутствующего заголовка без переменной исключения |
| 7 | Форматирование строки с завершающей запятой в сигнатуре |

php examples/21-php8-features/basic.php

Команды выполняются из корня проекта. Для второго запуска нужно загруженное расширение OPcache. Образец конфигурации: [jit.ini](../examples/21-php8-features/jit.ini).

### Почему необходимо обновлять PHP

PHP 8.5.12 устраняет две критические ошибки интерпретатора с возможностью удалённого выполнения кода без входа в приложение:

- [CVE-2026-109618](https://github.com/php/php-src/security/advisories/GHSA-w8hw-w9fx-j79w): при нехватке памяти очистка запроса могла использовать частично подготовленные внутренние данные.
- [CVE-2026-109619](https://github.com/php/php-src/security/advisories/GHSA-6wmf-4rv5-p3rp): следующий запрос в том же процессе мог обратиться к состоянию, память которого уже освобождена.

Это ошибки среды исполнения: валидация формы и перехват исключений в учебном скрипте не исправляют интерпретатор. Обновите пакеты, проверьте совместимость приложения, перезапустите все рабочие процессы и проверьте версии CLI и веб-среды отдельно. Поддерживаемые ветки также получили исправления в 8.4.27, 8.3.36 и 8.2.35. См. [официальное уведомление](https://www.php.net/archive/2026.php#2026-10-21-5).

Сведения и дополнения после релиза приведены в [разделе безопасности README](../README.md#безопасность-и-переход-на-php-8512), включая рекомендацию по `session.upload_progress.enabled` и обновлённые Windows-пакеты. Установка 8.5.12 не отменяет последующие обновления безопасности.

## 4. Практические задания

1. Создайте функцию с `int|float`, проверьте целое и дробное значение. С `strict_types=1` передайте массив и объясните `TypeError`.
2. Добавьте к методу собственный атрибут и прочитайте его через Reflection. Объясните, почему атрибут сам не вызывает метод.
3. Создайте подкласс `Message`, вызовите его фабрику и сравните имя полученного класса с ожидаемым.
4. Проверьте строковые функции для совпадения, несовпадения регистра и пустой подстроки. Затем передайте пустой заголовок в `readTitle()` и объясните результат.
5. Выполните пример с JIT и без него. Сравните результат вычисления и состояние JIT, не делая выводов о скорости по одному запуску.
6. Проверьте `php -v` и опишите, как отдельно подтвердить обновление PHP-FPM или среды Sail.

## 5. Частые ошибки и их решение

| Ошибка | Причина | Решение |
|---|---|---|
| `<<Lesson(...)>>` | Предварительный синтаксис из старой статьи | Используйте `#[Lesson(...)]` |
| Атрибут не запускает обработчик | Метаданные приняты за вызов | Прочитайте атрибут через Reflection и явно выполните нужное действие |
| Строка не принимается как Stringable | Интерфейс описывает объекты | Используйте `string|Stringable`, если нужны оба варианта |
| Поиск пустой подстроки даёт true | Это определённое поведение функций | Проверяйте непустое поисковое значение отдельно |
| JIT выключен в CLI | OPcache не загружен или не настроен | Проверьте расширение, enable_cli, буфер и режим JIT |
| CLI обновлён, сайт использует старый PHP | Разные установки или старые процессы | Проверьте веб-среду и перезапустите все рабочие процессы |

# Лекция 2: Типы данных PHP

## 1. Теоретическая часть

Тип значения и объявление типа — разные понятия. Восемь основных типов значений: `bool`, `int`, `float`, `string`, `array`, `object`, `resource`, `null`. Объявления дополнительно описывают допустимые значения и поведение функций. Например, `iterable` допускает массив или объект `Traversable`, а `never` описывает отсутствие обычного возврата из функции.

Ниже рассмотрена система типов PHP 8.5. Группировка основных значений на скалярные, составные и специальные удобна для обучения; в официальной системе составными типами называются объединения и пересечения.

### Скалярные типы (int, float, string, bool)

- **int** - целые числа
- **float** - числа с плавающей точкой. Название double встречается в старых API, но в объявлениях пишите `float`: `double` будет воспринят как имя класса
- **string** - строки (одинарные или двойные кавычки)
- **bool** - логический тип (true/false)

### Составные значения (array, object)

- **array** - индексированные или ассоциативные массивы
- **object** - экземпляры классов

### Специальные типы (null, resource)

- **null** - отсутствие значения
- **resource** - дескриптор внешнего ресурса, например открытого потока. Многие современные API возвращают объекты вместо ресурсов. В пользовательских объявлениях тип `resource` недоступен: используйте `is_resource()` и PHPDoc `@param resource`

### Типизация в современном PHP

С PHP 7.0+ поддерживаются объявления типов для параметров и возвращаемых значений. PHP 8.0 добавил union types, mixed, static return type.

### Union types и mixed в PHP 8

`int|float` допускает целое или дробное число, а `mixed` — любое значение, включая `null`. Имя переменной `$mixed` само по себе не задаёт тип. В режиме `declare(strict_types=1)` несовместимый аргумент вызывает `TypeError`; union type следует выбирать по контракту функции.

```php
function doubleNumber(int|float $value): int|float
{
    return $value * 2;
}

function valueType(mixed $value): string
{
    return get_debug_type($value);
}
```

Возвращаемый `static` и интерфейс `Stringable` разобраны в [лекции 21](21-php8-features.md); полный [пример](../examples/21-php8-features/basic.php) показывает их работу.

### Дополнительные объявления типов

| Тип | Значение и ограничения |
|---|---|
| `callable` | Вызываемое значение: замыкание, имя функции, подходящий массив с объектом/классом и методом, объект с `__invoke()`. Допустим для параметров и результата, но не для свойств; для свойства с замыканием используйте `Closure` |
| `iterable` | `array` или объект `Traversable`; подходит для `foreach`. Доступен с PHP 7.1, с PHP 8.2 является псевдонимом `array|Traversable` |
| `mixed` | Любое значение, включая `null`; с PHP 8.0. Не объединяется с другими типами и не записывается как `?mixed` |
| `void` | Только возвращаемый тип: функция не возвращает значение через `return выражение`. Разрешены `return;` и достижение конца тела; результат вызова фактически `null`. С PHP 7.1 |
| `never` | Только возвращаемый тип: функция выбрасывает исключение, завершает процесс или работает бесконечно. Нельзя использовать даже `return;`. С PHP 8.1 |
| `true`, `false`, `null` | Принимают ровно одно соответствующее значение. Самостоятельные `true`, `false` и `null` доступны с PHP 8.2; `false` и `null` разрешены в union types с PHP 8.0 |

`true` и `false` уточняют `bool`, а не создают новые виды значений. Запись `true|false` запрещена — используйте `bool`. `void` и `never` не включаются в объединения.

### Классы, интерфейсы, перечисления и относительные типы

Имена классов (`DateTimeImmutable`, собственный `User`), интерфейсов (`Stringable`, `Countable`) и перечислений (`enum Status`) можно использовать как типы. Объекты классов-наследников подходят для параметра базового класса, а реализации интерфейса — для параметра этого интерфейса. Варианты enum являются объектами; перечисления появились в PHP 8.1. Trait служит для повторного использования кода и не является типом параметра.

| Объявление | Смысл |
|---|---|
| `self` | Класс, в котором объявлен метод или свойство |
| `parent` | Непосредственный родитель этого класса; требует наличия родителя |
| `static` | Класс, через который вызван метод; допустим только как возвращаемый тип, с PHP 8.0 |

### Nullable, объединения, пересечения и DNF

| Запись | Допустимое значение | Версия |
|---|---|---|
| `?string` | Строка или `null`, эквивалент `string|null` | 7.1 |
| `int|string` | Один из перечисленных типов | 8.0 |
| `Countable&Iterator` | Объект, удовлетворяющий обоим типам | 8.1 |
| `(Countable&Iterator)|null` | Такой объект или `null`; DNF — объединение пересечений | 8.2 |

Пересечения допускают только типы классов и интерфейсов, а не `int&string`. Для нескольких nullable-вариантов используйте `int|string|null`, а не `?int|string`. Nullable-параметр не становится необязательным: для пропуска аргумента нужно значение по умолчанию, например `?string $name = null`.

### Объявления и строгий режим

Типы указываются у параметров, результата, свойств (с PHP 7.4) и констант классов (с PHP 8.3). У обычной локальной переменной нельзя написать `int $count = 1`; её тип определяется значением. PHPDoc вроде `list<int>` помогает анализаторам, но не является исполняемым объявлением PHP.

`declare(strict_types=1);` в начале файла отключает неявное скалярное приведение для вызовов из этого файла. Исключение: `int` допустим для параметра `float`. Строгий режим не проверяет бизнес-условия вроде положительного возраста. Для диагностики используйте `get_debug_type()`, `var_dump()`, `is_int()`, `is_callable()`, `is_iterable()` и `instanceof`.

Источники: [система типов PHP](https://www.php.net/manual/en/language.types.type-system.php), [объявления типов и ограничения](https://www.php.net/manual/en/language.types.declarations.php).

## 2. Синтаксис и основные концепции

```php
// Скалярные
$int = 42;
$float = 3.14;
$string = "Hello";
$bool = true;

// Составные
$array = [1, 2, 3];
$object = new stdClass();

// Функция с типизацией
function add(int $a, int $b): int { return $a + $b; }
```

## 5. Частые ошибки и их решение

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `TypeError` | Значение не соответствует контракту | Исправьте вызывающий код; расширяйте тип только если этого требует задача |
| Неожиданное приведение | Строка "123" + число | Явно приводите типы: `(int)$str` |
| Сравнение типов | `==` игнорирует тип | Используйте строгое сравнение `===` |
| Пустая строка как false | `"" == false` даёт true | Используйте `===` или `empty()` осознанно |
| `double` в сигнатуре | Это имя класса, а не псевдоним float | Пишите `float` |
| `resource` в сигнатуре | Не поддерживается как объявление | Проверяйте `is_resource()` |
| `callable` у свойства | Такое объявление запрещено | Для замыканий используйте `Closure` |
| `?string $name` нельзя пропустить | Nullable не означает необязательность | Добавьте `= null`, если пропуск допустим |
| `return null` в void-функции | Нельзя явно возвращать значение | Используйте `return;` или тип `null`, если именно это нужно |
| `array<int>` в сигнатуре | Это синтаксис PHPDoc, а не PHP | Используйте `array`, документируйте и проверяйте элементы отдельно |

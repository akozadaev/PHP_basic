# Лекция 20: Сессии в PHP

## 1. Теоретическая часть

### Работа с сессиями

- `session_start()` - запуск сессии (до любого вывода!)
- `$_SESSION` - массив для хранения данных сессии
- Данные сохраняются на сервере, идентификатор передаётся через cookie

### Настройка сессий

- `session_set_cookie_params()` - параметры cookie
- `ini_set('session.cookie_httponly', 1)` - защита от XSS
- `session_regenerate_id(true)` - защита от фиксации сессии

### Безопасность сессий

- HttpOnly, Secure, SameSite для cookie
- Регенерация ID при смене прав (логин)
- Таймаут неактивности (реализуется вручную)

### Управление данными сессии

- `session_unset()` - очистка переменных
- `session_destroy()` - уничтожение сессии
- `session_write_close()` - ранняя запись (освобождение блокировки)

### Обновление среды и обработка сессий

PHP 8.5.12 исправляет критическую CVE-2026-109619: состояние запроса могло использоваться после освобождения связанной памяти. Настройки cookie и `session_regenerate_id()` не заменяют обновление PHP. См. [уведомление разработчиков](https://github.com/php/php-src/security/advisories/GHSA-6wmf-4rv5-p3rp).

В [дополнении от 23 октября 2026 года](https://www.php.net/archive/2026.php) разработчики рекомендуют до следующего исправления отключить отслеживание загрузки через сессию из-за отдельного сценария CVE-2026-115560. Он требует включённого upload progress и смены `session.serialize_handler` с `php_binary` или `php_serialize` на `php` во время выполнения перед `session_start()`.

```ini
; php.ini или конфигурация пула/сервера до обработки запроса
session.upload_progress.enabled=0
```

После изменения перезапустите все рабочие процессы. Эта настройка отключает отслеживание прогресса через сессию, а не саму загрузку файлов. Не подменяйте её вызовом `ini_set()` внутри обработчика формы. Порядок обновления и дополнительные источники — в [README](../README.md#безопасность-и-переход-на-php-8512) и [лекции 21](21-php8-features.md).

## 2. Синтаксис и основные концепции

```php
session_start();
$_SESSION['user_id'] = 123;
session_regenerate_id(true);
session_destroy();
```

## 5. Частые ошибки и их решение

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Headers already sent | Вывод до session_start | session_start() в самом начале |
| Сессия не сохраняется | Cookie не отправляются | Проверьте path, domain, SameSite |
| Фиксация сессии | Один ID до и после логина | session_regenerate_id(true) после логина |
| Блокировка | Долгое выполнение скрипта | session_write_close() после чтения |
